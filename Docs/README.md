# Docs: File map

> Folder-level README. `Docs/` holds the written record of the project: rules,
> reasoning, reference, research, secrets. Code never lives here.

---

## What belongs here

- Binding rules (`Rules.md`) - read before every change.
- Reasoning log (`Thinking.md`) - why a decision was made, updated every round.
- Reference (`Technical.md`, `Logic.md`) - stack, terms, call chains.
- History (`Changelog.md`, `Change.md`) - what shipped, what was requested.
- Environment notes (`Workaround.md`, `Secrets.md`).
- Machine-readable maps (`Files_Info.json`, `Research.json`).

## What does not belong here

- Plans and specs -> `Plan/`.
- Test code or test results -> `Tests/`.
- CI inputs/outputs -> `Actions/`.
- Runnable code -> the package directory at the repo root.
