# internels

> Folder-level README. Non-public helper material: anything that supports the work but
> is not part of the product people install.

---

## What belongs here

- `skills/` - one markdown file per reusable skill, added only when genuinely useful.
  A skill file says when to use it, the exact steps, and the pitfalls.
- Drafts, notes, scratch designs that are not yet ready for `Docs/` or `Plan/`.

## What does not belong here

- Product code, product docs, tests, or anything the user needs to install archx.
- Anything that duplicates a doc in `Docs/` - link to it instead.

## Rule

Nothing here is imported by the package. If code needs it, it is not `internels/`.
