# internels: skills

> Folder-level README. One markdown file per skill, nothing else.

---

## Naming and shape

```
internels/skills/<skill-name>.md
```

Every skill file starts with a purpose line, then:

- **When to use it** - the trigger.
- **Steps** - exact commands, in order.
- **Pitfalls** - what has already gone wrong once and must not go wrong again.

## Rules

- A skill is added only when it will be used again; speculative skills are noise.
- If a skill is really a rule, it belongs in `Docs/Rules.md` instead.
- If a skill is really a workaround, it belongs in `Docs/Workaround.md`.
